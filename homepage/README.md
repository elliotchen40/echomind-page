# EchoMind

> 让爱，不止于回忆

EchoMind 是一个 AI 纪念系统，通过人工智能技术保存逝者的声音与样貌，让生者能够在思念时与那份温暖的"记忆"对话。

## 关于

- **核心理念**：这不是复活，是让爱延续
- **技术方式**：用 AI 保存声音与影像，作为思念时的陪伴
- **适用人群**：失去配偶/伴侣、失去年迈父母、想为孩子留下与长辈对话记忆的人

## 网站

落地页地址：[https://echomind-page.github.io](https://echomind-page.github.io)

## 技术栈

- 纯静态 HTML/CSS/JS
- 无框架依赖，轻量快速
- 响应式设计，支持移动端访问
